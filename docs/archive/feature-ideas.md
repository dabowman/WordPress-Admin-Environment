# Feature Ideas
feature ideas and requests from users and testers. 

- native support for color modes. Styles should include a mode key as a sibling to theme and regions. modes.dark.color would contan a new set of seeds for the theme provider. This would let the user define dark mode, high contrast mode, even modes that respond to other values supported by the theme provider. 
- the sidebar width should be user-modifiable with a little drag handle. 
- Support for the site-wide notification that does things like remind users to update to new wp-versions
- I want to be able to mix drilldown and tree styles for sub-menus in the menu renderer for the core engine.
