## Top-level structure

```json
{
  "$schema": "https://schemas.wp.org/wp/6.8/theme.json",
  "version": 3,
  "settings": {},
  "styles": {},
  "customTemplates": [],
  "templateParts": [],
  "patterns": [],
  "title": "My Theme"
}
```

- `$schema` — JSON schema URL for editor autocompletion. Use `https://schemas.wp.org/wp/6.8/theme.json` for 6.8 or `.../trunk/theme.json` for latest.
- `version` — **integer, required**. Use `3` for WordPress 6.6+.
- `settings` — controls which UI options appear and defines presets.
- `styles` — applies CSS to body, elements, and blocks.
- `customTemplates` — metadata for custom templates in `/templates/`.
- `templateParts` — metadata for template parts in `/parts/`.
- `patterns` — array of pattern slugs from WordPress.org Pattern Directory.
- `title` — theme display name (used in style variations).

## Preset slug naming conventions

Preset slugs become CSS custom properties (`--wp--preset--{category}--{slug}`), preset class names (`.has-{slug}-{category}`), and are referenced from patterns, style variations, and block markup. **Using the same slugs WordPress ships for its defaults is a compatibility contract** — patterns from the core Pattern Directory, child themes, style variations, and other themes all assume those names.

### WordPress default slugs (verified against Gutenberg `lib/theme.json`)

| Preset | Default slugs |
|---|---|
| `color.palette` | `black`, `cyan-bluish-gray`, `white`, `pale-pink`, `vivid-red`, `luminous-vivid-orange`, `luminous-vivid-amber`, `light-green-cyan`, `vivid-green-cyan`, `pale-cyan-blue`, `vivid-cyan-blue`, `vivid-purple` |
| `color.gradients` | `vivid-cyan-blue-to-vivid-purple`, `light-green-cyan-to-vivid-green-cyan`, `luminous-vivid-amber-to-luminous-vivid-orange`, `luminous-vivid-orange-to-vivid-red`, `very-light-gray-to-cyan-bluish-gray`, `cool-to-warm-spectrum`, `blush-light-purple`, `blush-bordeaux`, `luminous-dusk`, `pale-ocean`, `electric-grass`, `midnight` |
| `color.duotone` | `dark-grayscale`, `grayscale`, `purple-yellow`, `blue-red`, `midnight`, `magenta-yellow`, `purple-green`, `blue-orange` |
| `typography.fontSizes` | `small` (13px), `medium` (20px), `large` (36px), `x-large` (42px) |
| `spacing.spacingSizes` (auto-generated by `spacingScale`) | Numeric. `50` is always "Medium"; below descends by 10 (`40`, `30`, `20`, `10`); above ascends by 10 (`60`, `70`, `80`, …). Gutenberg's default 7-step scale produces `20`–`80`. |
| `shadow.presets` | `natural`, `deep`, `sharp`, `outlined`, `crisp` |
| `dimensions.aspectRatios` | `square`, `4-3`, `3-4`, `3-2`, `2-3`, `16-9`, `9-16` |
| `border.radiusSizes` | (no defaults — theme is sole source; see guidance below) |

### Rules

- **Match WordPress's slugs whenever you're defining the same semantic preset.** If you want a "small" font size, use `small`, not `sm` — otherwise `.has-small-font-size` from core patterns won't resolve against your theme.
- **Kebab-case, lowercase, ASCII only.** WordPress lowercases and converts internally; inconsistencies break `.has-{slug}-{category}` class matching.
- **Numeric slugs for spacing.** The scale generator hardcodes `50` = Medium, descends `40/30/20/10` below, ascends `60/70/80/...` above. If you skip `spacingScale` and define `spacingSizes` manually, **keep these numeric slugs** — `--wp--preset--spacing--50` is referenced from patterns, other themes, and block defaults. Using `sm`/`md`/`lg` here breaks portability.
- **Don't reuse a core slug for a different meaning** — e.g. don't redefine `medium` to be an uncommon size; users and patterns will expect the familiar value.
- **`defaultPalette: false` / `defaultFontSizes: false` / `defaultSpacingSizes: false`** suppress core defaults. If you keep defaults enabled AND define your own, both sets coexist (keyed by origin in v3) — name collisions between your theme and core resolve to theme origin, but this is confusing; prefer explicit opt-out.

### For `border.radiusSizes` (no WP defaults yet)

Since core ships no defaults, there is no official convention to match. Two common approaches:

- **Semantic (recommended for portability)** — `none`, `small`, `medium`, `large`, `full` / `pill`. Matches the spirit of core's `fontSizes`.
- **Numeric** — `10`/`20`/`30`/`40`/`50`. Matches core's `spacingSizes`. Useful if the theme treats radius as another unit of a coherent scale.

Whichever you pick, be consistent within the theme and document in the theme's README so child themes and patterns can target the slugs.

## Settings

### `settings.appearanceTools` (boolean, default: false)

Shorthand that enables: `background.backgroundImage`, `background.backgroundSize`, `border.color`, `border.radius`, `border.style`, `border.width`, `color.link`, `color.heading`, `color.button`, `color.caption`, `dimensions.aspectRatio`, `dimensions.height`, `dimensions.minHeight`, `dimensions.width`, `position.sticky`, `spacing.blockGap`, `spacing.margin`, `spacing.padding`, `typography.lineHeight`, `typography.textColumns`. Does **not** auto-populate preset arrays (`palette`, `fontSizes`, `spacingSizes`, `shadow.presets`, `border.radiusSizes`) — those must be defined explicitly.

### `settings.useRootPaddingAwareAlignments` (boolean, default: false)

Top-level only. When enabled, applies `styles.spacing.padding` to full-width block contents rather than the root block. Requires padding set as object with `top`, `right`, `bottom`, `left`.

### `settings.color`

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `palette` | `[{name, slug, color}]` | — | Color presets for the picker |
| `gradients` | `[{name, slug, gradient}]` | — | Gradient presets |
| `duotone` | `[{name, slug, colors}]` | — | Duotone filter presets |
| `custom` | boolean | `true` | Allow custom color picker |
| `customDuotone` | boolean | `true` | Allow custom duotone |
| `customGradient` | boolean | `true` | Allow custom gradients |
| `defaultPalette` | boolean | `true` | Show default color palette |
| `defaultGradients` | boolean | `true` | Show default gradients |
| `defaultDuotone` | boolean | `true` | Show default duotone |
| `background` | boolean | `true` | Allow background color |
| `text` | boolean | `true` | Allow text color |
| `link` | boolean | `false` | Allow link color |
| `heading` | boolean | `true` | Allow heading color |
| `button` | boolean | `true` | Allow button color |
| `caption` | boolean | `true` | Allow caption color |

### `settings.typography`

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `fontFamilies` | `[{name, slug, fontFamily, fontFace}]` | — | Font family presets |
| `fontSizes` | `[{name, slug, size, fluid}]` | — | Font size presets |
| `defaultFontSizes` | boolean | `true` | Show default font sizes (v3) |
| `customFontSize` | boolean | `true` | Allow custom font sizes |
| `fluid` | boolean/object | `false` | Enable fluid typography |
| `lineHeight` | boolean | `false` | Allow line-height control |
| `dropCap` | boolean | `true` | Enable drop cap |
| `fontStyle` | boolean | `true` | Allow font style |
| `fontWeight` | boolean | `true` | Allow font weight |
| `letterSpacing` | boolean | `true` | Allow letter spacing |
| `textDecoration` | boolean | `true` | Allow text decoration |
| `textTransform` | boolean | `true` | Allow text transform |
| `textColumns` | boolean | `false` | Allow column-count (6.6+) |
| `writingMode` | boolean | `false` | Allow writing-mode (6.6+) |
| `textAlign` | boolean | `true` | Allow text alignment (v3) |

**Fluid typography object:**
```json
{
  "fluid": {
    "minFontSize": "14px",
    "maxViewportWidth": "1600px",
    "minViewportWidth": "320px"
  }
}
```

Fluid generates `clamp()` values. Only works with `px`, `em`, or `rem` units. Sizes below `minFontSize` (default 14px) stay static.

**fontFace declaration:**
```json
{
  "fontFamilies": [
    {
      "name": "DM Sans",
      "slug": "dm-sans",
      "fontFamily": "\"DM Sans\", sans-serif",
      "fontFace": [
        {
          "fontFamily": "DM Sans",
          "fontWeight": "400 700",
          "fontStyle": "normal",
          "fontDisplay": "swap",
          "src": ["file:./assets/fonts/dm-sans/DMSans-Variable.woff2"]
        },
        {
          "fontFamily": "DM Sans",
          "fontWeight": "400 700",
          "fontStyle": "italic",
          "fontDisplay": "swap",
          "src": ["file:./assets/fonts/dm-sans/DMSans-Variable-Italic.woff2"]
        }
      ]
    }
  ]
}
```

**fontFace properties:** `fontFamily`, `fontWeight`, `fontStyle`, `fontDisplay`, `fontStretch`, `src` (array), `unicodeRange`, `sizeAdjust`, `ascentOverride`, `descentOverride`, `lineGapOverride`.

### `settings.spacing`

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `blockGap` | boolean/null | `null` | Enable `--wp--style--block-gap` |
| `margin` | boolean | `false` | Allow margin controls |
| `padding` | boolean | `false` | Allow padding controls |
| `units` | `[string]` | `["px","em","rem","vh","vw","%"]` | Available spacing units |
| `customSpacingSize` | boolean | `true` | Allow custom spacing values |
| `defaultSpacingSizes` | boolean | `true` | Show default spacing (v3) |
| `spacingSizes` | `[{name, slug, size}]` | — | Spacing size presets |
| `spacingScale` | `{operator, increment, steps, mediumStep, unit}` | — | Auto-generate spacing scale |

### `settings.layout`

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `contentSize` | string | — | Max-width of content (e.g., `"650px"`) |
| `wideSize` | string | — | Max-width of `.alignwide` (e.g., `"1200px"`) |
| `allowEditing` | boolean | `true` | Show layout UI controls |
| `allowCustomContentAndWideSize` | boolean | `true` | Allow custom width values |

### `settings.dimensions`

| Property | Type | Default |
|----------|------|---------|
| `aspectRatio` | boolean | falsy when absent |
| `defaultAspectRatios` | boolean | `true` |
| `aspectRatios` | `[{name, slug, ratio}]` | — |
| `height` | boolean | falsy when absent |
| `minHeight` | boolean | falsy when absent |
| `width` | boolean | falsy when absent |
| `dimensionSizes` | `[{name, slug, size}]` | — |

`dimensionSizes` is used almost exclusively at **block scope** rather than globally — core ships it on `core/button` only (width presets `25` / `50` / `75` / `100` as `%`). If you override, keep those slugs: core Button block UI renders the width picker against those exact values, and user-selected widths are stored as class names referencing them. See "Per-block settings" below for the canonical example.

### `settings.position`

| Property | Type | Default |
|----------|------|---------|
| `sticky` | boolean | `false` |

### `settings.shadow`

| Property | Type | Default |
|----------|------|---------|
| `defaultPresets` | boolean | `true` |
| `presets` | `[{name, slug, shadow}]` | — |

### `settings.border`

| Property | Type | Default |
|----------|------|---------|
| `color` | boolean | `false` |
| `radius` | boolean | `false` |
| `style` | boolean | `false` |
| `width` | boolean | `false` |
| `radiusSizes` | `[{name, slug, size}]` | — |

`radiusSizes` (added WP 6.9) defines border-radius presets. `size` is any CSS length with units (`"8px"`, `"0.5rem"`). Exposed as `--wp--preset--radius--{slug}` and referenced in theme.json as `"var:preset|radius|{slug}"`. Unlike `shadow` and `spacing`, there is no `defaultRadiusSizes` toggle — WordPress ships no default radius presets, so the theme is the sole source.

```json
{
  "settings": {
    "border": {
      "radius": true,
      "radiusSizes": [
        { "name": "None",   "slug": "none",   "size": "0" },
        { "name": "Small",  "slug": "small",  "size": "4px" },
        { "name": "Medium", "slug": "medium", "size": "8px" },
        { "name": "Large",  "slug": "large",  "size": "16px" },
        { "name": "Pill",   "slug": "pill",   "size": "9999px" }
      ]
    }
  },
  "styles": {
    "blocks": {
      "core/button": { "border": { "radius": "var:preset|radius|medium" } }
    }
  }
}
```

Slugs above follow the **semantic** convention (matches `fontSizes` shape). See "Preset slug naming conventions" above.

### `settings.background`

| Property | Type | Default |
|----------|------|---------|
| `backgroundImage` | boolean | `false` |
| `backgroundSize` | boolean | `false` |

### `settings.custom`

Generates custom CSS properties: `--wp--custom--{key}--{nested-key}: {value}`. CamelCase keys become kebab-case.

```json
{
  "custom": {
    "lineHeightBody": "1.6",
    "formInput": {
      "color": "#000",
      "borderColor": "#ccc"
    }
  }
}
```

Generates: `--wp--custom--line-height-body: 1.6`, `--wp--custom--form-input--color: #000`, `--wp--custom--form-input--border-color: #ccc`.

### Per-block settings

Override any setting for specific blocks:

```json
{
  "settings": {
    "color": { "custom": true },
    "blocks": {
      "core/paragraph": {
        "color": { "custom": false }
      },
      "core/heading": {
        "typography": { "fontSizes": [] }
      }
    }
  }
}
```

**Canonical block-scoped preset — `core/button` width:** Core ships `dimensionSizes` only on `core/button`, as the options that populate its width picker. The default slugs are `25`/`50`/`75`/`100` with `%` sizes — don't rename them; the block UI and serialized markup both reference them by slug.

```json
{
  "settings": {
    "blocks": {
      "core/button": {
        "dimensions": {
          "dimensionSizes": [
            { "name": "25%",  "slug": "25",  "size": "25%" },
            { "name": "50%",  "slug": "50",  "size": "50%" },
            { "name": "75%",  "slug": "75",  "size": "75%" },
            { "name": "100%", "slug": "100", "size": "100%" }
          ]
        }
      }
    }
  }
}
```

## Styles

Root-level styles apply to `body`. Styles also apply to `elements`, `blocks`, and `variations`.

### Root styles

```json
{
  "styles": {
    "color": {
      "background": "var:preset|color|base",
      "text": "var:preset|color|contrast",
      "gradient": ""
    },
    "typography": {
      "fontFamily": "var:preset|font-family|body",
      "fontSize": "var:preset|font-size|md",
      "fontStyle": "normal",
      "fontWeight": "400",
      "letterSpacing": "0",
      "lineHeight": "1.6",
      "textDecoration": "none",
      "textTransform": "none",
      "textColumns": "",
      "writingMode": "horizontal-tb",
      "textAlign": ""
    },
    "spacing": {
      "blockGap": "1.5rem",
      "padding": { "top": "0", "right": "2rem", "bottom": "0", "left": "2rem" },
      "margin": { "top": "0", "right": "0", "bottom": "0", "left": "0" }
    },
    "border": {
      "color": "", "radius": "", "style": "", "width": "",
      "top": { "color": "", "style": "", "width": "" },
      "right": {}, "bottom": {}, "left": {}
    },
    "shadow": "var:preset|shadow|natural",
    "outline": { "color": "", "offset": "", "style": "", "width": "" },
    "dimensions": { "aspectRatio": "", "minHeight": "" },
    "filter": { "duotone": "" },
    "background": {
      "backgroundImage": { "url": "file:./assets/images/bg.jpg" },
      "backgroundPosition": "center center",
      "backgroundRepeat": "no-repeat",
      "backgroundSize": "cover",
      "backgroundAttachment": "fixed"
    },
    "css": ".custom-class { opacity: 0.8; }",
    "elements": {},
    "blocks": {}
  }
}
```

### Elements

Targetable elements: `button`, `link`, `heading`, `h1`–`h6`, `caption`, `cite`, `textInput`, `select`.

Pseudo-states for `link` and `button` elements: `:link`, `:any-link`, `:visited`, `:hover`, `:focus`, `:focus-visible`, `:active`. Other elements do not support pseudo-states. Block-level pseudo-states (7.0+): `core/button` supports `:hover`, `:focus`, `:focus-visible`, `:active` directly on the block.

```json
{
  "elements": {
    "button": {
      "color": { "background": "var:preset|color|primary", "text": "var:preset|color|base" },
      "border": { "radius": "4px" },
      "typography": { "fontWeight": "600" },
      ":hover": { "color": { "background": "var:preset|color|contrast" } },
      ":focus": { "outline": { "color": "var:preset|color|primary" } }
    },
    "link": {
      "color": { "text": "var:preset|color|primary" },
      "typography": { "textDecoration": "underline" },
      ":hover": { "color": { "text": "var:preset|color|contrast" }, "typography": { "textDecoration": "none" } }
    },
    "heading": {
      "typography": { "fontFamily": "var:preset|font-family|heading", "fontWeight": "700", "lineHeight": "1.2" }
    },
    "h1": { "typography": { "fontSize": "var:preset|font-size|xxl" } },
    "h2": { "typography": { "fontSize": "var:preset|font-size|xl" } },
    "h3": { "typography": { "fontSize": "var:preset|font-size|lg" } }
  }
}
```

### Per-block styles

```json
{
  "blocks": {
    "core/paragraph": {
      "typography": { "lineHeight": "1.8" }
    },
    "core/button": {
      "border": { "radius": "999px" },
      "variations": {
        "outline": {
          "border": { "width": "2px" },
          "css": "border-color: currentColor;"
        }
      }
    },
    "core/table": {
      "css": "& thead th { background: var(--wp--preset--color--contrast); color: var(--wp--preset--color--base); }"
    }
  }
}
```

The `css` property supports `&` nesting where `&` becomes the block's root selector.

## Template configuration

```json
{
  "customTemplates": [
    { "name": "page-no-title", "title": "Page Without Title", "postTypes": ["page"] },
    { "name": "single-portfolio", "title": "Portfolio Single", "postTypes": ["portfolio"] }
  ],
  "templateParts": [
    { "name": "header", "title": "Header", "area": "header" },
    { "name": "footer", "title": "Footer", "area": "footer" },
    { "name": "sidebar", "title": "Sidebar", "area": "uncategorized" }
  ],
  "patterns": ["hero-banner-with-overlap-images"]
}
```

`templateParts` areas: `header`, `footer`, `uncategorized`, `navigation-overlay`. Custom areas registered via `default_wp_template_part_areas` filter.
